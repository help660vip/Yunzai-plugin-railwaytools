# 命令渲染测试清单

- 命令实现文件：`apps/railway-tools.js`
- 触发格式：Yunzai 消息事件中的 `#命令 参数`，支持连续空白和英文字母大小写容错。
- 实际输出、状态及截图验收结果由 `test-runner.js` 写入 [report.md](report.md)。

| 命令 | 成功结果 | 空结果或错误 | 测试参数来源 |
|---|---|---|---|
| `#车迷帮助` | Puppeteer 图片 | 渲染失败时原文字 | 插件帮助常量 |
| `#车号 <车次>` | 有担当记录时 Puppeteer 图片 | 普通文字 | 从候选车次的真实详情派生 |
| `#车次 <车次>` | 有停站信息时 Puppeteer 图片 | 普通文字 | 依次尝试 G895、G6005、C7213、D169、T222 |
| `#车次 <车组号>` | 有担当记录时 Puppeteer 图片 | 普通文字 | 从真实车组担当结果派生 |
| `#查询 <车次>` | 有停站信息时 Puppeteer 图片 | 普通文字 | 依次尝试 G895、G6005、C7213、D169、T222 |
| `#大屏 <车站>` | 有列车列表时 Puppeteer 图片 | 普通文字 | 从真实车次停站结果派生 |
| `#线路 <线路>` | 查询成功时 Puppeteer 图片 | 普通文字 | 依次尝试真实线路候选项 |
| `#车站 <车站>` | 查询成功时 Puppeteer 图片 | 普通文字 | 从真实车次停站结果派生 |
| `#机车信息 HXD1D-1898` | 实拍图消息段与普通文字 | 普通文字 | 轨上名录真实数据 |

## 图片验收

- 五个候选车次 G895、G6005、C7213、D169、T222 必须全部实际请求并分别记录，随后才使用第一个有效详情派生车号、车组、车站和大屏测试。
- 生成真实 PNG 时，报告记录图片数量、IHDR 尺寸、分页顺序，以及字体、背景和 GitHub 页脚的人工验收入口。
- 没有 TRSS-Yunzai 共享 Puppeteer 时不创建占位图，图片数量、尺寸、分页、字体、背景和 GitHub 页脚均明确标记 `SKIP`。
- `#机车信息` 不进入 Puppeteer 渲染路径；格式化结果必须包含实拍图消息段，并且全部普通文字不得包含 URL。
